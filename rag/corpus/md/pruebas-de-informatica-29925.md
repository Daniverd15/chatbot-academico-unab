# Pruebas de Informática

La Cultura Informática en la UNAB está conformada por cinco competencias: 

- Cultura digital 

- Vida en línea 

- MS Word 

- MS Excel 

- MS PowerPoint 

 Las cinco competencias se pueden obtener mediante pruebas de Informática, cada competencia tiene su respectiva prueba. Las pruebas son teórico prácticas, cada una tiene una duracion máxima de 30 minutos y se aprueban obteniendo un puntaje mayor o igual al 60% de las preguntas contestadas correctamente. 
 Pruebas programadas. 
 Durante el semestre se programan dos fechas para la presentación de pruebas para estudiantes continuos, una al inicio y otra al final del semestre. Para la presentación de las pruebas se debe realizar el pago correspondiente a las pruebas que se requiera presentar, posteriormente se debe diligenciar un formulario de inscripción que permitirá indicar la hora para la presentación de las pruebas.  
 Las pruebas no se pueden repetir el mismo día. 
 Cuando se abren inscripciones para pruebas programadas, se publica una noticia en miportalu.unab.edu.co. 

 Pruebas extemporáneas. 
 La prueba extemporánea se realiza en fechas diferentes a las programadas al inicio y final de cada semestre, se programan cuando el estudiante la solicita.
